# 價格基準診斷

此修正只拆開既有 price gate 的原因文字，不改比較規則、價格、模型、排名、權重、計畫、交易模擬或歷史資料。

- 缺少快照價、缺少日K收盤及非有限正數各有明確原因。
- 兩欄皆有數值但超過既有容差時，標示價格基準不一致，不再暗示沒有收盤數字。
- 原容差仍為 `max(0.01, abs(close) * 0.00001)`，以 Decimal 比較並包含邊界。
- `price_basis.diagnostic` 只補充既有比較的絕對差額、容差與收盤來源標示／交易日。來源不明時維持空值，不從市場、日期或其他參考價推測。來源標示不代表 source gate 已通過，Yahoo 不會被改名或升級為 Alpaca。
- 影子交易計畫頁對舊報表只在顯示時替換混合原因文字。舊報表未提供差額、容差或來源診斷時明列未提供，不以瀏覽器重算閘門；所有狀態、篩選與數量沿用原判定。
- 原生研究投影保持既有白名單，不新增原始價格欄位；下次正常產報會沿用更精確的失敗原因。`quarter.source_fully_verified` 仍是保守的固定 False，不是逐檔驗證結果，也不代表投資效能驗收完成。

發布程式不代表既有研究分片已重產。不得為驗收觸發產報、改寫歷史或交易模擬。檢查 GitHub Pages 的實際 JS 版本與新舊資料相容顯示；Vercel 首頁現有 iframe 可呈現該頁，不等於其獨立私有研究頁面已更新。
