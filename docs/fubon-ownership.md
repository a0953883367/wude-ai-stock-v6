# 富邦盤後籌碼補充

使用官方 Fubon Neo 2.4.0 的三大法人買賣超、集保股權分散、董監持股查詢。
範圍為既有股票池的台股與台灣 ETF；ETF 董監持股標示不適用。

GitHub 早中晚報通知完成後，以既有 OIDC 驗證向 Railway 取資料，
寫入獨立 `reports/fubon_ownership.json`，由股票卡顯示。
帳號、密碼、憑證仍保留在 Railway；不寫入報表或 GitHub。
本機 `fubon_runner.py` 也能沿用現有登入建立相同補充報表。

每批至多五檔，每項查詢間隔一秒；法人快取六小時，其餘二十四小時。
限速或中繼失敗後停止本輪新增查詢，下次報表重試。
資料期別與取得時間分開顯示，查無資料不填成零，失敗保留歷史但標示失敗。
董監持股採最新公告月份，不使用今天日期取代公告期別。

這是顯示與資料核對補充，不進入正式 V6 分數、排名、權重或影子訓練；不含下單呼叫。
期貨歷史 K 線尚未包含在本次三項籌碼接入。

驗收需確認 Railway 完成新版部署、下一次固定報表的補充步驟成功，
並核對補充 JSON 的 `available_count`、各項 `status`、`data_date`。
健康檢查的憑證已配置並不代表上游查詢成功。
