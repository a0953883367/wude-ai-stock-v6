# 綜合研究判斷：重用來源與能力界線

本次把既有研究判斷放在逐檔報告前面，而非再增加一套評分／策略。`report_research.py` 讀同批 `decision_hub.json` 宣告的完整分檔，直接重用 short recommendation 與 reason；讀同批 `trade_plan_shadow.json` 的來源／失效檢核；方向、因子與結果仍由 PR365／367 的完整 frozen reader 提供。來源批次、版本、路徑及重複身分不符就不採用。官方日曆沿用 `_timing`，禁止網路刷新；以產報時顯式時鐘重新核對已完成交易日，而不是拿報表產生日期冒充行情日期。

沒有新分數、買賣門檻、權重、影子升版規則或模型呼叫。`can_scale` 只翻譯為可進一步評估的研究候選，不是現在可買；`avoid` 保留既有中樞的短線排除理由，不因公開執行未放行而把所有研究判為沒有機會。若中樞建議和凍結方向相反，兩者並列並說明衝突，不自創權重裁定勝負。支持／反對因子是對各筆凍結方向而言，不一定支持中樞建議；中樞理由另列。新聞空掃描不當成利多。

新進場與「若已持有」分開：後者不假設使用者實際持倉，也不從資料缺漏直接推出賣出。列明還缺持有成本、部位、期限、原始持有理由及風險承受範圍。既有短線排除時，只能建議原本以短線轉強為理由的持有人重審該理由，不能據此指定減碼比例或退出價。

原有定性改判條件照錄，但「量價／資金同步轉強」未保存可驗證定義，不能當成已驗證進場／失效規則；不把中樞原本的盤中15～30分鐘監控當作使用者可以執行的全天監看方案。來源或失效檢查缺漏另列，不以補新價位消除缺口。

三個月只看 UP_60D／UP_63D 的可用性、凍結日期與最新已完成交易日是否一致，以及同資產組的既有 learning 狀態。`forecast_dates_current` 僅驗日期，不是來源／投資效能全部合格。現有 learning 是挑戰模型試驗／累積狀態，不足以證明本次使用模型的投資判斷有效，因此不將任何試驗狀態或樣本數自行轉成通過。明列缺少與使用版本對應的樣本外／前向績效、進場、失效及持有風險規則；NEXT_1D／UP_5D 不延伸為三個月。

5～10年目前不能產出有充分依據的公司投資判斷。既有單點財報數值不等於已完成競爭力、成長持續性、現金流／資本支出、負債、稀釋／資本配置、估值敏感度與長期驗證。ETF 另缺基金策略、成分穿透、費用與追蹤研究。126交易日模型也不填補此缺口。

全部 `all_analysis.json.data` 身分保留原序與正式欄位，逐檔均有短線、三個月、5～10年判斷或確切缺口。`complete_projection` 仍只代表完整身分對帳。整合錯誤沿用 PR367 的原報告保護；未改正式 V6、排程、通知、下單、授權或費用。程式／樣本不等於 ChatGPT 原生任務已接入；本 PR 只提交供父層獨立審查，不自行合併。
