# 方向錯誤診斷與固定棄權前向對照

核對基準 main 036c276；2026-10-09 19:06:26 報告：729 個錯誤事件中546個歸類 direction_calibration（74.9%）。這是錯誤事件的分布，不是所有預測的失敗率。

`performance._classify_error_case` 的 direction_calibration 是其他原因皆未匹配時的剩餘分類，不能證明門檻是主因。`model_lab` 的 score/confidence 是加權證據強度，未經機率校準；不能直接計算 Brier 分數或宣稱79.6%勝率。既有 `tw_threshold_calibration` 是歷史重算，適合診斷，不是事前註冊的前向驗證。

## 唯一新增對照

現有 `update_model_learning` 每次更新時讀取不可變 prediction_history，在 model_learning.json 的 direction_calibration_validation 保留註冊時間、固定規則與事前決策。

- 固定 full_day、一日結果；原共識方向為基準。
- 唯一變數：強度低於65時影子棄權，否則保留原方向。65只是固定研究假設，不是根據歷史最佳結果選出的新正式門檻。
- 四個市場／資產分開列方向報酬、命中率、覆蓋率及新增棄權列數；未有樣本的報酬與命中率為 null。
- 初次註冊時排除當下所有歷史快照；之後只收註冊時間後且無任何結果的快照，在結果可見前凍結決策。不補填已知結果的決策。
- 必須是目前資料契約、validation_eligible=true、雜湊驗證成功。已註冊快照若遭改動，保留原決策並記錄排除原因。
- 未來日期結果、無正式評估日期、非有限報酬不計入。重跑不增加樣本。
- 單一股票列不視為獨立事件；不同股票可能相關，不能單憑列數或三次勝出晉升。
- 方向報酬非實際交易損益，未扣成本；不宣稱能改善扣成本收益。只有前向證據足夠後再人工審查。

不修改正式V6、排名、權重、20／60日門檻、原始影子／歷史資料或下單；不增加服務與付費呼叫。新比較沒有自動晉升或中央影子信任更新路徑。
